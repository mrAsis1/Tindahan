# Tindahan coding instructions

Use Ponytail Full for Tindahan coding tasks. Understand the relevant code first, reuse existing patterns, prefer built-in features, and make the smallest change that fully meets the requirements.

Use the installed Matt Pocock skills when appropriate:

- diagnosing-bugs for broken behavior or performance problems.
- tdd when I request test-first development or a feature needs meaningful behavior tests.
- setup-matt-pocock-skills only for initial configuration or changes to that configuration.

Follow the selected skill’s workflow. Ponytail must not skip its required questions, confirmations, tests, or documentation.

Preserve security, validation, error handling, accessibility, and explicitly requested behavior. Avoid unnecessary dependencies and speculative abstractions.

After changes, run appropriate checks and briefly explain what changed, what passed, and anything that could not be verified. When I request a Ponytail review or audit, report findings before applying fixes.
